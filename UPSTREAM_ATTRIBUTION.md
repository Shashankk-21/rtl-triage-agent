# Upstream attribution

RTL Triage Agent is an independent implementation created from scratch for this
MVP. It is conceptually inspired by **MEIC: “Re-thinking RTL Debug
Automation using LLMs” (ICCAD 2024)** by the original MEIC research authors.

Original research repository: <https://github.com/Satan-23333/reproduce-MEIC-ICCAD>

This project does not copy or depend on the original repository's source code,
datasets, or implementation, and does not imply that its author inherited or
authored the MEIC research.
